Política de privacidad

Última actualización: 25 de septiembre de 2026

Corta Clips es un programa que cada persona instala y ejecuta en su propio ordenador. No existe un servidor de Corta Clips que reciba, almacene o analice tus vídeos, tus datos personales ni tus cuentas. Esta web (corta-clips) solo muestra información y actúa como página de retorno para el inicio de sesión de Instagram.

Qué datos se tratan y dónde

  • Vídeos, audios, transcripciones y clips: se descargan, procesan y guardan en la carpeta outputs de tu ordenador.
  • Credenciales y tokens de acceso (OpenAI, YouTube, TikTok, Instagram, Upload‑Post): se guardan solo en tu ordenador, en los archivos .env y .data/tokens.json, con permisos de lectura restringidos a tu usuario.
  • Datos de tus cuentas sociales: Corta Clips lee únicamente el nombre y la foto del perfil conectado para mostrártelo, y usa el permiso de publicación solo cuando tú pulsas «Publicar».

Servicios de terceros

Según lo que configures, tu ordenador se comunica directamente con:

  • OpenAI (API o tu cuenta de ChatGPT mediante Codex): recibe la transcripción del vídeo para elegir los momentos y, si eliges transcribir con Whisper, el audio. Si usas la transcripción local, el audio no sale de tu ordenador.
  • Anthropic (opcional, si eliges Claude): recibe la transcripción para el mismo fin.
  • YouTube (Google), TikTok e Instagram (Meta): reciben el clip, su título y su descripción cuando decides publicarlo.
  • Upload‑Post (opcional): recibe el clip y sus textos si eliges ese servicio.
  • La plataforma de origen del vídeo (por ejemplo, YouTube) cuando descargas un enlace.

Cada servicio trata los datos según su propia política de privacidad.

Uso de los datos de Google, TikTok y Meta

Los datos obtenidos a través de las API de YouTube, TikTok e Instagram se usan exclusivamente para mostrarte qué cuenta está conectada y para subir los vídeos que tú eliges. No se venden, no se comparten con terceros, no se usan con fines publicitarios y no se utilizan para entrenar modelos de IA. El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cookies y analítica

Ni la app ni esta web usan cookies de seguimiento, publicidad ni herramientas de analítica.

Tus derechos y cómo borrar tus datos

Como todo se guarda en tu ordenador, tienes control total: consulta la página de eliminación de datos para desconectar cuentas y borrar la información.

Cambios

Si esta política cambia, se actualizará la fecha de esta página.

Contacto
