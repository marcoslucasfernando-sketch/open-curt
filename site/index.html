Cómo funciona

Instala y abre

Descarga el proyecto y haz doble clic en iniciar.command. Instala lo necesario y abre la app en http://127.0.0.1:8766.

Conecta la IA

Inicia sesión con tu cuenta de ChatGPT (OAuth) o añade una API key de OpenAI para usar GPT‑6 Luna.

Crea clips

Pega el enlace, elige cuántos clips y su duración. Revisa, ajusta el corte y edita textos si quieres.

Publica

Conecta YouTube, TikTok o Instagram una vez y publica cada clip con un clic. Esta web solo sirve de página de retorno segura para el inicio de sesión de Instagram.
